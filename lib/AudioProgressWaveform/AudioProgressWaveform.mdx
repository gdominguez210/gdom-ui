# AudioProgressWaveform

<ViewSource href="AudioProgressWaveform" />

An interactive audio waveform visualization component that displays playback progress and allows seeking. It provides a visual representation of the audio waveform with customizable appearance and color options.

## Features

- **Interactive Seeking**: Click anywhere on the waveform to seek to that position in the audio
- **Visual Progress**: Shows played and unplayed sections with distinct colors
- **Customizable Appearance**: Control bar width, gaps, and height to match your design
- **Multiple Color Modes**: Choose from solid or gradient coloring with hover effects
- **Responsive Design**: Automatically scales to fit its container
- **Keyboard Navigation**: Support for keyboard-based seeking with acceleration
- **AudioPlayer Integration**: Seamlessly works with the AudioPlayer component system

## Usage

The AudioProgressWaveform component can be used in two ways: 

- [**With the AudioPlayer Component System**](#with-audioplayer-component-system-recommended)
- [**Standalone**](#standalone-usage)

### With AudioPlayer Component System (Recommended)

The recommended way to use this component is through the AudioPlayer component system, which automatically handles all the required audio integration props for you:

<Source
  language="tsx"
  dark
  code={`
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';

const tracks = [
  {
    id: '1',
    title: 'Example Track',
    author: 'Artist Name',
    src: '/path/to/audio.mp3',
    thumbnail: '/path/to/cover.jpg',
  },
];

const IntegratedAudioWaveform = () => {
  return (
    <AudioPlayer.Provider tracks={tracks}>
      <AudioPlayer.Root className="flex flex-col gap-4">
        <AudioPlayer.ProgressWaveform
          colorMode="solid"
          progressColor="#0066cc"
          color="#cccccc"
          className="h-[150px] w-full"
        />
        <AudioPlayer.ControlAudio />
        {/* Other AudioPlayer components like controls, info, etc. would go here */}
      </AudioPlayer.Root>
    </AudioPlayer.Provider>
  );
};`} />

#### How the AudioPlayer Integration Works

When using `AudioPlayer.ProgressWaveform`, the component automatically receives all required props through React context:

| Required Prop | Provided By | Description |
|---------------|-------------|-------------|
| `audioRef` | `AudioPlayer.Provider` | Reference to the audio element managed by the AudioPlayer |
| `isActive` | `AudioPlayer.Provider` | Automatically managed based on playback state |
| `duration` | `AudioPlayer.Provider` | Total duration of the current track |
| `onProgressChange` | `AudioPlayer.Provider` | Function to handle seeking operations |
| `onPreviewTimeChange` | `AudioPlayer.Provider` | Function to handle hover preview time updates |

The AudioPlayer integration provides several key benefits:
- **Zero Configuration**: No need to manually set up audio integration code
- **Automatic State Management**: Waveform automatically syncs with playback
- **Proper Event Handling**: All seek and preview events are properly managed

### Standalone Usage

When used standalone, you need to manually provide all the required audio integration props. This approach gives you full control but requires more setup code:

<Source
  language="tsx"
  dark
  code={`
import { useRef, useState } from 'react';
import { AudioProgressWaveform } from '@gdominguez210/gdom-ui/AudioProgressWaveform';

const StandaloneAudioWaveform = () => {
  const audioRef = useRef<HTMLAudioElement>(null);
  const [isActive, setIsActive] = useState(false);
  const [duration, setDuration] = useState(0);

  const handleProgressChange = (time: number) => {
    if (audioRef.current) {
      audioRef.current.currentTime = time;
    }
  };

  const handlePreviewTimeChange = (time: number | null) => {
    // Handle preview time changes (e.g., show tooltip with time)
    console.log('Preview time:', time);
  };

  return (
    <div className="flex flex-col gap-4">
      <AudioProgressWaveform
        audioRef={audioRef}
        isActive={isActive}
        duration={duration}
        onProgressChange={handleProgressChange}
        onPreviewTimeChange={handlePreviewTimeChange}
        progressColor="#0066cc"
        color="#cccccc"
        className="h-[150px] w-full"
      />
      <audio
        ref={audioRef}
        src="/path/to/audio.mp3"
        controls
        onPlay={() => setIsActive(true)}
        onPause={() => setIsActive(false)}
        onEnded={() => setIsActive(false)}
        onDurationChange={(e) => setDuration(e.currentTarget.duration)}
      />
    </div>
  );
};`} />
