# Icon

<ViewSource href="Icon" />

The Icon component is a polymorphic, tree-shakable SVG icon system that provides a consistent way to include icons in your UI. All icons are sourced from [Remix Icon](https://remixicon.com/), providing a comprehensive set of consistent and customizable icons.

## Features

- **Tree-shakable architecture** for optimized bundle size
- **Consistent sizing** relative to text using `em` units
- **Customizable colors** via Tailwind text color utilities
- **Accessibility support** with proper ARIA attributes
- **TypeScript support** with type safety
- **Scalable vector graphics** that maintain quality at any size
- **Support for custom SVGs** with consistent styling

## Usage Patterns

There are two main ways to use icons in your application:

### 1. Dedicated Icon Components (Recommended)

Each icon is available as a dedicated component, which is the most efficient approach for tree-shaking:

<Source
  language="tsx"
  dark
  code={`
// Import specific icon components directly (best for tree-shaking)
import { IconStarLine } from '@gdominguez210/gdom-ui/IconStarLine';
import { IconPlayFill } from '@gdominguez210/gdom-ui/IconPlayFill';

// Use them directly in your JSX
<IconStarLine className="text-yellow-400" />
<IconPlayFill className="text-blue-500" size="large" />
`}
/>

### 2. Base Icon Component

The base Icon component can be used with SVG components:

<Source
  language="tsx"
  dark
  code={`
import { Icon } from '@gdominguez210/gdom-ui/Icon';
import { ReactComponent as StarLineSvg } from '@gdominguez210/gdom-ui/assets/svgs/star-line.svg';
import { ReactComponent as PlayFillSvg } from '@gdominguez210/gdom-ui/assets/svgs/play-fill.svg';

// Using the base Icon component
<Icon as={StarLineSvg} className="text-yellow-400" />
<Icon as={PlayFillSvg} className="text-blue-500" />
`}
/>

## Using Custom SVGs

You can use your own SVG components with the Icon component:

<Source
  language="tsx"
  dark
  code={`
import { Icon } from '@gdominguez210/gdom-ui/Icon';
import { ReactComponent as CustomSvg } from './path/to/custom.svg';

<Icon as={CustomSvg} className="text-green-500" />
`}
/>

This allows you to maintain consistent styling across all icons in your application, whether they come from this library or from custom sources.

### Styling Approach

The Icon component:

- Uses the `fill-current` utility to inherit color from text color
- Sets height to `1em` by default, making it scale with text size
- Supports all SVG attributes like `className`, `aria-label`, etc.

<Source
  language="tsx"
  dark
  code={`
// Icons inherit text color
<div className="text-red-500">
  <IconStarLine />
</div>

// Icons inherit text size
<div className="text-2xl">
  <IconPlayFill />
</div>

// Custom classes can override defaults
<IconStarLine className="h-8 w-8 text-blue-500" />
`}
/>

### Bundle Size Optimization

The Icon system is designed for optimal bundle size:

- Each icon is exported as its own component, enabling tree-shaking
- Only the icons you import are included in your bundle
- For applications where bundle size is critical, use the dedicated icon components

<Source
  language="tsx"
  dark
  code={`
// Only these specific icons will be included in your bundle
import { IconPlayFill } from '@gdominguez210/gdom-ui/IconPlayFill';
import { IconPauseFill } from '@gdominguez210/gdom-ui/IconPauseFill';

function PlayButton({ isPlaying, onToggle }) {
  return (
    <button onClick={onToggle}>
      {isPlaying ? <IconPauseFill /> : <IconPlayFill />}
    </button>
  );
}
`}
/>

For internal usage where bundle size is less critical (like documentation or admin panels), consider using the `IconLibrary` component instead, which allows referencing icons by name.
