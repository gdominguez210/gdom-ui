# IconLibrary

<ViewSource href="IconLibrary" />

The IconLibrary component provides a name-based approach to using icons in your UI. It's designed for convenience in development and prototyping, but for production applications, the dedicated icon components are recommended for better bundle optimization. All icons are sourced from [Remix Icon](https://remixicon.com/), providing a comprehensive set of consistent and customizable icons.

## Features

The IconLibrary component offers these key benefits:

- **Name-based API** for referencing icons without direct imports
- **TypeScript support** with autocompletion for icon names
- **Simplified integration** for rapid development and prototyping
- **Consistent styling** inherited from the base Icon component
- **Unified icon registry** for centralized icon management

This component is particularly well-suited for:
- Internal tools and admin panels
- Documentation sites
- Prototyping and development
- Applications where developer convenience is prioritized over bundle size

## Usage Comparison

### IconLibrary Component (Development-Friendly)

The IconLibrary component allows referencing icons by name without individual imports:

<Source
  language="tsx"
  dark
  code={`
import { IconLibrary } from '@gdominguez210/gdom-ui/IconLibrary';

// Reference icons by name
<IconLibrary name="star-line" />
<IconLibrary name="play-fill" className="w-6 h-6" />
<IconLibrary name="volume-up-fill" className="text-blue-500" />
`}
/>

### Dedicated Icon Components (Production-Optimized)

For production applications, use the dedicated icon components for better tree-shaking:

<Source
  language="tsx"
  dark
  code={`
// Import only the icons you need
import { IconStarLine } from '@gdominguez210/gdom-ui/IconStarLine';
import { IconPlayFill } from '@gdominguez210/gdom-ui/IconPlayFill';
import { IconVolumeUpFill } from '@gdominguez210/gdom-ui/IconVolumeUpFill';

// Use them directly
<IconStarLine />
<IconPlayFill className="w-6 h-6" />
<IconVolumeUpFill className="text-blue-500" />
`}
/>

## TypeScript Usage

The component provides TypeScript types for all available icons:

<Source
  language="tsx"
  dark
  code={`
import { IconLibrary, type IconName } from '@gdominguez210/gdom-ui/IconLibrary';

// Type safe icon names with autocompletion
const iconName: IconName = 'star-line';

function IconSelector({ selectedIcon, onSelect }) {
  return (
    <div className="flex gap-2">
      {['star-line', 'play-fill', 'volume-up-fill'].map((name) => (
        <button
          key={name}
          onClick={() => onSelect(name)}
          className={selectedIcon === name ? 'text-blue-500' : ''}
        >
          <IconLibrary name={name as IconName} className="h-6 w-6" />
        </button>
      ))}
    </div>
  );
}
`}
/>

## Bundle Size Considerations

The IconLibrary component includes references to all icons in your bundle, which impacts application size. For production applications, use the dedicated icon components:

<Source
  language="tsx"
  dark
  code={`
// ❌ Not recommended for production (includes all icons)
import { IconLibrary } from '@gdominguez210/gdom-ui/IconLibrary';

<IconLibrary name="star-line" />
<IconLibrary name="play-fill" />

// ✅ Recommended for production (only bundles what you use)
import { IconStarLine } from '@gdominguez210/gdom-ui/IconStarLine';
import { IconPlayFill } from '@gdominguez210/gdom-ui/IconPlayFill';

<IconStarLine className="text-yellow-400" />
<IconPlayFill className="text-blue-500" />
`}
/>

The dedicated icon components:
- Are automatically tree-shakable by bundlers
- Include only the specific icons you import
- Provide a more direct and performant approach
- Support the same props and styling options

## Styling and Accessibility

Both the IconLibrary component and dedicated icon components share the same styling capabilities and accessibility features. All icons:

- Inherit text color using Tailwind's text utilities
- Automatically scale with font size (default height is `1em`)
- Support ARIA attributes for accessibility
- Can be styled with custom classes
