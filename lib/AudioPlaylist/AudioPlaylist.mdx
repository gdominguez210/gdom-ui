# AudioPlaylist

The AudioPlaylist is a flexible, composable interface for displaying audio track lists that integrates seamlessly with the AudioPlayer component. Built using a compound component pattern, it allows for maximum customization and flexibility in implementation.

<Stories />

## Component Architecture

The AudioPlaylist uses a compound component pattern with a two-tier architecture similar to the AudioPlayer:

### Context-Connected Components

The main `AudioPlaylist` namespace exports all subcomponents that integrate with the audio playlist context:

- These components handle state management and playlist interactions automatically
- They're accessible through the `AudioPlaylist.ComponentName` pattern
- These are client components that use React hooks and context

Components that handle events (like AudioPlaylist.ControlToggle, AudioPlaylist.Dismiss, etc.) follow a consistent pattern:

- They accept standard event handlers as props (onClick, onChange, etc.)
- Internal handlers run first to maintain core functionality
- Your custom handlers are called afterward with the event object

<Source
  language="tsx"
  dark
  code={`
<AudioPlaylist.ControlToggle
  onClick={(e) => {
    console.log('Playlist toggle clicked');
  }}
/>

<AudioPlaylist.Dismiss
  onClick={(e) => {
    console.log('Dismiss button clicked');
  }}
/>
`} />

This approach allows you to add custom behavior while the components automatically maintain their connection to the playlist context.

### Primitive Components

Each context-connected component is built on top of a primitive component:

- Primitive components are purely prop-driven with no dependency on context
- They handle presentation, and some default assignments for accessibility
- They can be imported directly for custom implementations
- Since they don't use React hooks or browser APIs, **primitive components can be used as server components** in Next.js

This separation creates a flexible system that enables both quick implementation through the context components and advanced customization through primitives, while also allowing for server-side rendering optimizations.

### Polymorphic Components

All AudioPlaylist components are built as polymorphic components, which means they can render as any HTML element or React component. This provides maximum flexibility for integration into various UI patterns.

<Source
  language="tsx"
  dark
  code={`
// Render as a div (default)
<AudioPlaylist.Root>
  Content goes here
</AudioPlaylist.Root>

// Render as a section

<AudioPlaylist.Root as="section">Content goes here</AudioPlaylist.Root>

// Render as a custom component

<AudioPlaylist.Root as={CustomContainer}>Content goes here</AudioPlaylist.Root>
`} />

Each component accepts an `as` prop that determines the rendered element, along with all props valid for that element type. This allows you to maintain semantic HTML structure while using AudioPlaylist components.

### Styling Approach

All AudioPlaylist components are designed for flexible styling:

- Use **className props** with Tailwind CSS classes
- Apply **custom CSS classes**
- Use **inline style objects**
- Work with **CSS-in-JS solutions** like styled-components

Components use `twMerge` internally to intelligently merge Tailwind CSS classes, so your classes override defaults rather than conflicting with them:

<Source
  language="tsx"
  dark
  code={`
// Override the background color and padding
<AudioPlaylist.Root className="bg-blue-800 p-6 rounded-xl">
  <AudioPlaylist.Header className="text-2xl font-bold text-white">
    Playlist
  </AudioPlaylist.Header>
</AudioPlaylist.Root>

// Using inline styles

<AudioPlaylist.Tracks style={{ marginTop: '2rem', opacity: 0.9 }} />

// Combining approaches (Tailwind, style object, custom class)

<AudioPlaylist.Track.Root
  className="my-custom-class rounded-md p-2 hover:bg-gray-700"
  style={{ borderBottom: '1px solid rgba(255,255,255,0.1)' }}
/>
`} />

### Accessibility Features

The AudioPlaylist components are built with accessibility as a core principle:

- All controls use semantic HTML elements
- Proper ARIA attributes for controls and content
- Keyboard navigation support
- Focus management for interactive elements

  language="tsx"
  dark

## Available Subcomponents

Each component is available through the main `AudioPlaylist` namespace or can be imported directly. Primitive components are also available for advanced customization.

### Core Components

#### Root Container

The main wrapper component that provides layout and styling for the playlist.

<Source
  language="tsx"
  dark

## Integration with AudioPlayer

The AudioPlaylist component is designed to integrate seamlessly with the AudioPlayer component. When both components share the same AudioPlayerContext, the playlist can interact with and control the audio playback.

<Source
  language="tsx"
  dark
  code={`
// Example of integrated usage
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';
import { AudioPlaylist } from '@gdominguez210/gdom-ui/AudioPlaylist';

<AudioPlayer.Provider tracks={tracks}>
  <AudioPlaylist.Provider>
    {/* Playlist UI */}
    <AudioPlaylist.ExpandableContainer>
      <AudioPlaylist.Root>
        <AudioPlaylist.Header>
          Playlist
          <AudioPlaylist.Dismiss />
        </AudioPlaylist.Header>
        <AudioPlaylist.ScrollableContainer maxHeight="300px">
          <AudioPlaylist.Tracks>
            {tracks.map((track, index) => (
              <AudioPlaylist.Track.Provider
                key={index}
                track={track}
                index={index}
              >
                <AudioPlaylist.Track.Root>
                  <AudioPlaylist.Track.Image />
                  <div>
                    <AudioPlaylist.Track.Title />
                    <AudioPlaylist.Track.Author />
                  </div>
                </AudioPlaylist.Track.Root>
              </AudioPlaylist.Track.Provider>
            ))}
          </AudioPlaylist.Tracks>
        </AudioPlaylist.ScrollableContainer>
      </AudioPlaylist.Root>
    </AudioPlaylist.ExpandableContainer>

    {/* AudioPlayer UI */}
    <AudioPlayer.Root>
      <AudioPlayer.Controls>
        {/* ... player controls ... */}
      </AudioPlayer.Controls>
      <div className="flex justify-end">
        <AudioPlaylist.ControlToggle />
      </div>
    </AudioPlayer.Root>

  </AudioPlaylist.Provider>
</AudioPlayer.Provider>
`} />
