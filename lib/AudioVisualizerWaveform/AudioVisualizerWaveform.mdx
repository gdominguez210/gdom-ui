## Features

The AudioVisualizerWaveform component provides several key features:

- **Real-time Waveform Visualization**: Renders the audio waveform in real-time using the Web Audio API
- **Customizable Appearance**: Control line width, color, and segmentation to match your design
- **Multiple Color Modes**: Choose from static, amplitude-based, frequency-based, spectrum, or dynamic coloring
- **Responsive Design**: Automatically scales to fit its container with proper pixel density handling
- **Performance Optimized**: Uses efficient rendering techniques to maintain smooth animation
- **AudioPlayer Integration**: Seamlessly works with the AudioPlayer component system for a complete audio experience

## Usage

The AudioVisualizerWaveform component can be used in two ways: 

- [**With the AudioPlayer Component System**](#with-audioplayer-component-system-recommended)
- [**Standalone**](#standalone-usage)

### With AudioPlayer Component System (Recommended)

The recommended way to use this component is through the AudioPlayer component system, which automatically handles all the required Web Audio API integration props for you:

<Source
  language="tsx"
  dark
  code={`
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';

const tracks = [
  {
    id: '1',
    title: 'Example Track',
    author: 'Artist Name',
    src: '/path/to/audio.mp3',
    thumbnail: '/path/to/cover.jpg',
  },
];

const IntegratedAudioVisualizer = () => {
  return (
    <AudioPlayer.Provider tracks={tracks}>
      <AudioPlayer.AudioContextProvider>
        <AudioPlayer.Root className="flex flex-col gap-4">
          <AudioPlayer.VisualizerWaveform
            colorMode="amplitude"
            lineColor="#029CFD"
            lineWidth={2}
            className="h-[200px] w-full"
          />
          <AudioPlayer.ControlAudio />
          {/* Other AudioPlayer components like controls, info, etc. would go here */}
        </AudioPlayer.Root>
      </AudioPlayer.AudioContextProvider>
    </AudioPlayer.Provider>
  );
};`} />

#### How the AudioPlayer Integration Works

When using `AudioPlayer.VisualizerWaveform`, the component automatically receives all required props through React context:

| Required Prop | Provided By | Description |
|---------------|-------------|-------------|
| `audioRef` | `AudioPlayer.Provider` | Reference to the audio element managed by the AudioPlayer |
| `isActive` | `AudioPlayer.Provider` | Automatically managed based on playback state |
| `audioContextRef` | `AudioPlayer.AudioContextProvider` | Reference to the shared Web Audio API context |
| `isAudioContextReady` | `AudioPlayer.AudioContextProvider` | Status flag for the AudioContext |
| `createAudioSource` | `AudioPlayer.AudioContextProvider` | Function to create and manage audio source nodes |
| `deleteAudioSource` | `AudioPlayer.AudioContextProvider` | Function to clean up audio source nodes |

The AudioPlayer integration provides several key benefits:
- **Zero Configuration**: No need to manually set up Web Audio API code
- **Resource Sharing**: Uses a single shared AudioContext for all audio components
- **Automatic State Management**: Visualization automatically syncs with playback
- **Proper Cleanup**: Handles all resource cleanup and disconnection

### Standalone Usage

When used standalone, you need to manually provide all the required Web Audio API integration props. This approach gives you full control but requires more setup code:

<Source
  language="tsx"
  dark
  code={`
import { useRef, useState, useEffect } from 'react';
import { AudioVisualizerWaveform } from '@gdominguez210/gdom-ui/AudioVisualizerWaveform';

const StandaloneAudioVisualizer = () => {
  const audioRef = useRef<HTMLAudioElement>(null);
  const audioContextRef = useRef<AudioContext | null>(null);
  const audioSourceRef = useRef<MediaElementAudioSourceNode | null>(null);
  const [isActive, setIsActive] = useState(false);
  const [isAudioContextReady, setIsAudioContextReady] = useState(false);

  useEffect(() => {
    const audioContext = new (window.AudioContext || window.webkitAudioContext)();
    audioContextRef.current = audioContext;
    setIsAudioContextReady(true);

    return () => {
      // Clean up source nodes before closing context
      if (audioSourceRef.current) {
        audioSourceRef.current.disconnect();
        audioSourceRef.current = null;
      }
      audioContext.close();
    };
  }, []);

  const createAudioSource = (audioElement: HTMLAudioElement) => {
    if (!audioContextRef.current) return null;
    audioSourceRef.current = audioContextRef.current.createMediaElementSource(audioElement);
    return audioSourceRef.current;
  };

  const deleteAudioSource = (audioElement: HTMLAudioElement) => {
    if (audioSourceRef.current) {
      audioSourceRef.current.disconnect();
      audioSourceRef.current = null;
    }
    return true;
  };

  return (
    <div className="flex flex-col gap-4">
      <AudioVisualizerWaveform
        audioRef={audioRef}
        isActive={isActive}
        audioContextRef={audioContextRef}
        isAudioContextReady={isAudioContextReady}
        createAudioSource={createAudioSource}
        deleteAudioSource={deleteAudioSource}
        lineColor="#029CFD"
        colorMode="amplitude"
        lineWidth={2}
        className="h-[200px] w-full"
      />
      <audio
        ref={audioRef}
        src="/path/to/audio.mp3"
        controls
        onPlay={() => setIsActive(true)}
        onPause={() => setIsActive(false)}
        onEnded={() => setIsActive(false)}
      />
    </div>
  );
};`} />
