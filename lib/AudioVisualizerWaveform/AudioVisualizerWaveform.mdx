## Features

The AudioVisualizerWaveform component provides several key features:

- **Real-time Waveform Visualization**: Renders the audio waveform in real-time using the Web Audio API
- **Customizable Appearance**: Control line width, color, and segmentation to match your design
- **Multiple Color Modes**: Choose from static, amplitude-based, frequency-based, spectrum, or dynamic coloring
- **Responsive Design**: Automatically scales to fit its container with proper pixel density handling
- **Performance Optimized**: Uses efficient rendering techniques to maintain smooth animation
- **AudioPlayer Integration**: Seamlessly works with the AudioPlayer component system for a complete audio experience

## Component Usage

The AudioVisualizerWaveform component can be used both standalone with a direct audio element reference or as part of the AudioPlayer component system:

### Standalone Usage

<Source
  language="tsx"
  dark
  code={`
import { useRef, useState } from 'react';
import { AudioVisualizerWaveform } from '@gdominguez210/gdom-ui/AudioVisualizerWaveform';

const MyAudioVisualizer = () => {
const audioRef = useRef<HTMLAudioElement>(null);
const [isActive, setIsActive] = useState(false);

return (

<div>
  <AudioVisualizerWaveform
    audioRef={audioRef}
    isActive={isActive}
    colorMode="amplitude"
    lineColor="#029CFD"
    lineWidth={2}
    className="h-[200px] w-full"
  />
  <audio
    ref={audioRef}
    src="/path/to/audio.mp3"
    controls
    onPlay={() => setIsActive(true)}
    onPause={() => setIsActive(false)}
  />
</div>
); }; `} />

### With AudioPlayer Component System

## Color Modes

The AudioVisualizerWaveform component supports five color modes:

- **static**: The entire waveform uses the same color as defined by `lineColor`
- **amplitude**: Colors vary based on the audio amplitude, with louder parts appearing brighter
- **frequency**: Colors vary based on the frequency position across the waveform
- **spectrum**: Full spectrum coloring across the waveform (like a rainbow visualizer)
- **dynamic**: Colors dynamically adjust based on audio intensity, creating the most vibrant effect

<Source
  language="tsx"

## Line Customization

The component offers several options to customize the appearance of the waveform:

<Source
  language="tsx"
  dark
  code={`
// Bold waveform with thick lines
<AudioPlayer.VisualizerWaveform
  lineColor="#FF6C22"
  lineWidth={4}        // Thicker line for more bold visualization
  segmentCount={20}    // Fewer segments for smoother color transitions
/>

// Detailed waveform with more color segments

<AudioPlayer.VisualizerWaveform
  lineColor="#F875AA"
  lineWidth={1.5} // Thinner line for more detailed visualization
  segmentCount={60} // More segments for detailed color variations
  colorMode="spectrum" // Using spectrum color mode for rainbow effect
/>
`} />

## Integration with Audio Context

The AudioVisualizerWaveform automatically manages the Web Audio API setup, but also accepts optional parameters for more control:

<Source
  language="tsx"
  dark

  lineColor="#029CFD"

  smoothingTimeConstant={0.85} // Control how much the visualization smooths between frames
/>
`}
