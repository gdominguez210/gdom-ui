# CanvasResponsive

<ViewSource href="CanvasResponsive" />

A responsive canvas component that automatically manages canvas resolution and scaling based on container dimensions, device pixel ratio, and window resize events.

## API Reference

## Features

- **High-DPI Support:** Automatically adjusts canvas resolution based on the device pixel ratio, ensuring crisp rendering on retina and high-DPI displays. This prevents the blurry appearance common with canvas elements on high-resolution screens.

- **Custom DPR Support:** Provides a `devicePixelRatio` prop to override the native device pixel ratio. This enables avoiding fractional DPR issues, consistent rendering across devices, higher quality rendering via supersampling, and testing different DPR scenarios.

- **Coordinate System Normalization:** Sets up the canvas context with a transformation matrix that maintains a 1:1 coordinate system, regardless of the device pixel ratio. This means you can use the same coordinates in your drawing code regardless of the display density.

- **Responsive Resizing:** Uses ResizeObserver to detect when the canvas's container size changes and automatically adjusts the canvas dimensions accordingly. This ensures the canvas always fills its container properly and maintains the correct aspect ratio.

- **Performance Optimization:** Throttles resize operations to prevent performance issues during continuous resize events, with an optional framerate limit. Provides an `onResize` callback for efficient content redrawing after size changes.

## Usage

The CanvasResponsive component consists of two main parts:

- **CanvasResponsive Component**: A React component that renders a canvas element with the appropriate props and refs.
- **useCanvasResponsive Hook**: A custom hook that handles the canvas scaling and resizing logic.

This separation allows for flexibility - you can use either the full component or just the hook in your own canvas implementation.

### Using the Component

The simplest way to use the responsive canvas functionality is to use the CanvasResponsive component directly:

<Source
  language="tsx"
  dark
  code={`
import { CanvasResponsive } from '@gdominguez210/gdom-ui/CanvasResponsive';
import { useRef, useEffect } from 'react';

const MyCanvasComponent = () => {
    const canvasRef = useRef<HTMLCanvasElement>(null);

    useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;

        const ctx = canvas.getContext('2d');
        if (!ctx) return;

        // Your drawing code here
        ctx.fillStyle = 'blue';
        ctx.fillRect(10, 10, 100, 100);

    }, []);

    return <CanvasResponsive ref={canvasRef} className="w-full h-64" />;
};
`} />

### Using the Hook

For more custom implementations, you can use the useCanvasResponsive hook directly with your own canvas element:

<Source
  language="tsx"
  dark
  code={`
import { useCanvasResponsive } from '@gdominguez210/gdom-ui/CanvasResponsive';
import { useEffect, useCallback } from 'react';

const MyCustomCanvas = () => {

    const drawContent = useCallback(() => {
      const canvas = canvasRef.current;
      if (!canvas) return;

      const ctx = canvas.getContext('2d');
      if (!ctx) return;

      // Your drawing code here
      ctx.fillStyle = 'red';
      ctx.fillRect(10, 10, 100, 100);
    }, []);

    const canvasRef = useCanvasResponsive({ 
      frameRate: 30,
      devicePixelRatio: 2, // Prevents visual banding and provides supersampling
      onResize: drawContent // Redraw when canvas size changes
    });

    useEffect(() => {
      drawContent();
    }, [drawContent]);

    return <canvas ref={canvasRef} className="w-full h-64 border border-gray-300" />;
};
`} />
