# AudioVisualizerFrequencyBars

A highly customizable audio frequency visualizer that displays audio spectrum data as vertical bars, with support for various color modes and responsive design.

<DocumentationNav />

## Features

The AudioVisualizerFrequencyBars component provides several key features:

- **Real-time Frequency Analysis**: Visualizes audio frequency data in real-time using the Web Audio API
- **Customizable Appearance**: Control bar count, colors, gaps, and height to match your design
- **Multiple Color Modes**: Choose from static, frequency-based, intensity-based, spectrum, or dynamic coloring
- **Responsive Design**: Automatically scales to fit its container with proper pixel density handling
- **Performance Optimized**: Uses efficient rendering techniques to maintain smooth animation
- **AudioPlayer Integration**: Seamlessly works with the AudioPlayer component system for a complete audio experience

## Component Usage

The AudioVisualizerFrequencyBars component can be used both standalone with a direct audio element reference or as part of the AudioPlayer component system:

### Standalone Usage

<Source
  language="tsx"
  dark
  code={`
import { useRef, useState } from 'react';
import { AudioVisualizerFrequencyBars } from '@gdominguez210/gdom-ui/AudioVisualizerFrequencyBars';

const MyAudioVisualizer = () => {
const audioRef = useRef<HTMLAudioElement>(null);
const [isActive, useState] = useState(false);

return (

<div>
  <AudioVisualizerFrequencyBars
    audioRef={audioRef}
    isActive={isActive}
    colorMode="intensity"
    barColor="#029CFD"
    className="h-[200px] w-full"
  />
  <audio
    ref={audioRef}
    src="/path/to/audio.mp3"
    controls
    onPlay={() => setIsActive(true)}
    onPause={() => setIsActive(false)}
  />
</div>
); }; `} />

### With AudioPlayer Component System

## Color Modes

The AudioVisualizerFrequencyBars component supports five color modes:

- **static**: All bars use the same color as defined by `barColor`
- **frequency**: Colors vary based on frequency position, with lower frequencies closer to the base color
- **intensity**: Colors vary based on amplitude, with louder frequencies appearing brighter
- **spectrum**: Full spectrum coloring across frequency range (like a rainbow visualizer)
- **dynamic**: Colors dynamically adjust based on audio intensity, creating the most vibrant effect

<Source
  language="tsx"
  dark
  code={`

/>

## Bar Customization

The component offers several options to customize the appearance of the frequency bars:

<Source
  language="tsx"
  dark
  code={`
// High-resolution visualization with many narrow bars
<AudioPlayer.VisualizerFrequencyBars
  barColor="#FF6C22"
  barCount={256}       // More bars for detailed frequency display
  barGapRatio={0.001}  // Very small gaps between bars
/>

// Low-resolution visualization with fewer, wider bars

<AudioPlayer.VisualizerFrequencyBars
  barColor="#F875AA"
  barCount={32} // Fewer bars for a classic equalizer look
  barGapRatio={0.015} // Wider gaps between bars
  heightMultiplier={2} // Taller bars
  minBarHeight={0.05} // Minimum bar height (as proportion of container)
/>
`} />

## Integration with Audio Context

The AudioVisualizerFrequencyBars automatically manages the Web Audio API setup, but also accepts optional parameters for more control:

<Source
  language="tsx"
  dark
  code={`
// Using custom Web Audio API parameters
<AudioPlayer.VisualizerFrequencyBars
  barColor="#029CFD"
  fftSize={2048}               // Higher FFT size for more detailed analysis
  smoothingTimeConstant={0.85} // Control how much the visualization smooths between frames
/>
`}
/>
