## Features

- **Clean Amplitude Bars Visualization**: Displays audio amplitude data as vertical bars
- **Customizable Appearance**: Control bar width, gap ratio, colors, and height to match your design
- **Responsive Design**: Automatically scales to fit its container while maintaining visual proportions. The component intelligently samples data when there are too many points to display clearly, ensuring the waveform maintains visual quality across all device sizes while preserving the overall shape and important features.
- **Performance Optimized**: Uses efficient canvas rendering for smooth visuals

## Examples

<UsageNote>
    This component expects pre-processed amplitude data (an array of normalized amplitude values
    between 0-1). It does not convert audio files to amplitude data, as that conversion process
    depends on specific application requirements and is left to the consumer.

    **Data Resolution:** For optimal performance, a amplitude data array of 100-1000
    entries is recommended. While the component can handle larger datasets providing pre-sampled
    data when possible will improve initial rendering performance.
</UsageNote>

## Usage

The AudioWaveform component can be used as a standalone visualization:

### Basic Usage

<Source
  language="tsx"
  dark
  code={`
import { AudioAmplitudeBars } from '@gdominguez210/gdom-ui/AudioAmplitudeBars';

const MyWaveform = () => {

    // Array of normalized amplitude values (0-1)
    const amplitudeData = [0.5, 0.6, 0.8, 0.4, 0.7, 0.3, 0.9, ...];

    return (
        <AudioAmplitudeBars
            amplitudeData={amplitudeData}
            color="#333333"
            barGapRatio={0.003}
            minBarWidth={2}
            heightScale={0.8}
        />
    );

}; `} />

## Advanced Customization

For more advanced customization, you can use the `getBarColor` function to provide dynamic coloring:

<Source
  language="tsx"
  dark
  code={`
<AudioAmplitudeBars
 amplitudeData={amplitudeData}
  getColor={(barInfo) => {
    // barInfo contains: position, value, index
    
    // Example: Color bars based on amplitude
    if (barInfo.value > 0.7) return '#ff3300';  // Loud sections
    if (barInfo.value > 0.4) return '#ff9900';  // Medium sections
    return '#cccccc';                          // Quiet sections
    
    // Example: Color based on position
    // return \`hsl(\${barInfo.position * 360}, 100%, 50%)\`;  // Rainbow effect
  }}
  barGapRatio={0.003}
  minBarWidth={2}
/>
`}
/>
