# AudioPlayer

The AudioPlayer is a flexible, composable audio playback interface that provides a comprehensive set of controls and display elements for audio content. Built using a polymorphic component pattern, it allows for maximum customization and flexibility in implementation.

## Overview

The AudioPlayer uses a compound component pattern, where multiple specialized components work together through a shared context. This approach allows developers to:

- Customize the layout and appearance of the player
- Include or exclude specific controls and information displays
- Maintain full control over styling while leveraging built-in functionality
- Use semantic HTML elements through polymorphic components

## Basic Usage

The AudioPlayer requires a `ContextProvider` that manages the audio state and provides track data to all child components. Here's a basic implementation:

  <Source
    language="tsx"
    dark
    code={`
import { AudioPlayer } from '@lib/AudioPlayer';

function MyAudioPlayer() {
const tracks = [
{
id: '1',
title: 'Song Title',
artist: 'Artist Name',
audioUrl: '/path/to/audio.mp3',
imageUrl: '/path/to/cover.jpg',
},
];

return (

    <AudioPlayer.ContextProvider tracks={tracks}>
      <AudioPlayer>
        <AudioPlayer.Info>
          <AudioPlayer.Image />
          <AudioPlayer.Title />
          <AudioPlayer.Author />
        </AudioPlayer.Info>
        <AudioPlayer.Controls />
        <AudioPlayer.ProgressBar />
      </AudioPlayer>
    </AudioPlayer.ContextProvider>

); }`} />

## Polymorphic Components

All components in the AudioPlayer system are polymorphic, meaning they can be rendered as any HTML element or custom component using the `as` prop:

<Source
  language="tsx"
  dark
  code={`
<AudioPlayer.Info as="section">
  <AudioPlayer.Title as="h2" />
  <AudioPlayer.Author as="span" />
</AudioPlayer.Info>
`}
/>

## Styling

The AudioPlayer components come with minimal default styling and can be customized using:

- className props for Tailwind CSS classes
- Custom CSS
- Styled-components or other CSS-in-JS solutions

The base component uses Tailwind CSS utilities for basic layout and appearance, which can be overridden or extended as needed.

## Accessibility

The AudioPlayer components are built with accessibility in mind, providing:

- Proper ARIA attributes for media controls
- Keyboard navigation support
- Screen reader-friendly status updates
- Semantic HTML structure

## Available Components

All context-connected components are available through the main `AudioPlayer` import (e.g. `AudioPlayer.Controls`, `AudioPlayer.ProgressBar`). Base components can be imported directly from their respective modules.

### Main Container

- **AudioPlayer** - The main container component with context integration
- **AudioPlayerBase** - The base container component without context dependencies

<Source
  language="typescript"
  dark
  code={`

`}
/>

- **AudioPlayerControls** - The controls container with play/pause, next/previous, loop, and shuffle buttons

## Available Hooks

All hooks can be imported from either the barrel file of their related component (e.g. `@lib/AudioPlayerControls`) or directly from their respective modules. Some hooks are designed to work with the AudioPlayer context, while others can be used independently.

### Context Hooks

- **useAudioPlayerContextState** - Hook to access the AudioPlayer state context
- **useAudioPlayerContextDispatch** - Hook to access the AudioPlayer dispatch context

<Source
  language="typescript"
  dark
  code={`
import { useAudioPlayerContextState, useAudioPlayerContextDispatch } from '@lib/AudioPlayerContextProvider';
`}
/>

### Control Hooks

- **useAudioPlayerControls** - Hook for managing audio playback controls (play/pause, next/previous, loop, shuffle)
- **useAudioPlayerKeyboardControls** - Hook for handling keyboard shortcuts

<Source
  language="typescript"
  dark
  code={`
import { useAudioPlayerControls, useAudioPlayerKeyboardControls } from '@lib/AudioPlayerControls';
`}
/>

### Progress Bar Hook

- **useAudioPlayerProgressBar** - Hook for managing progress bar interactions and animations

<Source
  language="typescript"
  dark
  code={`
import { useAudioPlayerProgressBar } from '@lib/AudioPlayerProgressBar';
`}
/>

### Time Hook

- **useAudioPlayerTime** - Hook for formatting and displaying audio duration

<Source
  language="typescript"
  dark
  code={`
import { useAudioPlayerTime } from '@lib/AudioPlayerTime';
`}
/>
