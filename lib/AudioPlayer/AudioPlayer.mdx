# AudioPlayer

<ViewSource href="AudioPlayer" />

The AudioPlayer is a flexible, composable audio playback interface that provides a comprehensive set of controls and display elements for audio content. Built using a compound component pattern, it allows for maximum customization and flexibility in implementation.

## Features


- [**Two-Tier Architecture**](docs/core-concepts-two-tier-components--docs): Context-connected components for state management and primitive components for presentation.

- [**Polymorphic Components**](docs/core-concepts-polymorphic-components--docs): Render as different HTML elements or React components using the `as` prop.

- **Consistent Event Handling**: Internal handlers run first to maintain core functionality, then your custom handlers are called.

- **Comprehensive Controls**: Complete suite of audio playback controls including play/pause, volume, seek, and track navigation.

- **Flexible Layout**: Arrange components in any layout and style to match your design system.

- **Accessibility-First**: Built with proper ARIA attributes, keyboard navigation, and screen reader support.

See the [Core Concepts](/docs/core-concepts-introduction--docs) for more details on the architectural patterns used throughout GDOM-UI.

## Available Subcomponents

Each component is available through the main `AudioPlayer` namespace or can be imported directly. Primitive components are also available for advanced customization.

### Core Components

#### Root Container

The main wrapper component that provides layout and styling for the audio player.

<Source
  language="tsx"
  dark
  code={`
// Compound component usage
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';
<AudioPlayer.Root>...</AudioPlayer.Root>

// Direct import
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer/AudioPlayer';

<AudioPlayer>...</AudioPlayer>

// Primitive component
import { AudioPlayerPrimitive } from '@gdominguez210/gdom-ui/AudioPlayer';

<AudioPlayerPrimitive>...</AudioPlayerPrimitive>
`} />

#### Provider

Provides audio state and context to all child components. Required at the root level.

<Source
  language="tsx"
  dark
  code={`
// Compound component usage
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';
<AudioPlayer.Provider tracks={tracks}>...</AudioPlayer.Provider>

// Direct import
import { AudioPlayerContextProvider } from '@gdominguez210/gdom-ui/AudioPlayerContextProvider';

<AudioPlayerContextProvider tracks={tracks}>...</AudioPlayerContextProvider>
`} />

AudioPlayer includes several audio visualization components that can be added to enhance the player experience.

<Source
  language="tsx"
  dark
  code={`

#### Frequency Bars Visualizer

Displays a real-time frequency spectrum visualization as animated vertical bars. Shows different frequency ranges of the audio being played, similar to an equalizer display.

<Source
  language="tsx"
  dark
  code={`

// Direct import

// With custom styling and options

  barColor="rgba(59, 130, 246, 1)"
  barCount={32}
  barGapRatio={0.3}
  heightMultiplier={1.5}
  minBarHeight={3}
  colorMode="gradient"
  className="h-24 w-full rounded-md bg-gray-100"
/>

// With rainbow color effect
<AudioPlayerVisualizerFrequencyBars 
  colorMode="rainbow"
  barCount={64}
  className="h-36 w-full rounded-md"
/>
`} />
