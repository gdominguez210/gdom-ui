# Getting Started with GDOM-UI

A comprehensive guide to installing and using the GDOM-UI component library in your projects.

<DocumentationNav />

## Installation

You can install GDOM-UI using your preferred package manager:

  <div className="border rounded-md p-4">
    <Source
      language="bash"
      dark
      code={`npm install @gdominguez210/gdom-ui`}
    />
        <Source
      language="bash"

    />
        <Source
      language="bash"

      code={`pnpm add @gdominguez210/gdom-ui`}
    />

## Basic Usage

After installation, you can start importing and using components from GDOM-UI in your application.

### 1. Import components

Each component can be imported directly from the library:

<Source
  language="tsx"
  dark
  code={`import { Button } from '@gdominguez210/gdom-ui/Button';

// Or namespaced compound components
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';

// Or individual components
import { AudioPlayerImage } from '@gdominguez210/gdom-ui/AudioPlayerImage';`}
/>

### 2. Use the components in your application

GDOM-UI components follow a composable, easy-to-implement pattern:

<Source
  language="tsx"
  dark
  code={`import React from 'react';
import { Button } from '@gdominguez210/gdom-ui/Button';

function App() {
  return (
    <div className="p-4">
      <h1 className="text-xl mb-4">Welcome to my app</h1>
      
      <Button variant="primary" onClick={() => console.log('Hello World!')}>Click me</Button>
    </div>
  );}`}
/>

### Example: Using the AudioPlayer Component

The AudioPlayer is a complex, compound component that showcases GDOM-UI's component architecture that favors composability over configuration:

<Source
  language="tsx"
  dark
  code={`import React from 'react';
import { AudioPlayer } from '@gdominguez210/gdom-ui/AudioPlayer';

// Sample track data
const tracks = [
  {
    id: '1',
    title: 'Sample Track 1',
    author: 'Artist Name',
    source: '/path/to/audio-file-1.mp3',
    artwork: '/path/to/image-1.jpg',
  },
  {
    id: '2',
    title: 'Sample Track 2',
    author: 'Another Artist',
    source: '/path/to/audio-file-2.mp3',
    artwork: '/path/to/image-2.jpg',
  }
];

function AudioPlayerExample() {
  return (
    <AudioPlayer.Provider tracks={tracks}>
      <AudioPlayer.Root className="p-4 bg-gray-100 rounded-lg">
        <div className="flex items-center gap-4">
          <AudioPlayer.Image className="w-16 h-16 rounded" />
          <div>
            <AudioPlayer.Title className="font-bold" />
            <AudioPlayer.Author className="text-gray-600" />
          </div>
        </div>
        
        <AudioPlayer.ProgressBar className="my-4" />
        
        <div className="flex justify-between items-center">
          <AudioPlayer.Time className="text-sm" />
          
          <AudioPlayer.Controls className="flex gap-2">
            <AudioPlayer.ControlPrevious />
            <AudioPlayer.ControlPlay />
            <AudioPlayer.ControlNext />
          </AudioPlayer.Controls>
          
          <AudioPlayer.Volume>
            <AudioPlayer.VolumeButton />
            <AudioPlayer.VolumeSlider />
          </AudioPlayer.Volume>
        </div>
      </AudioPlayer.Root>
    </AudioPlayer.Provider>
  );
}`}
/>

## CSS Integration

GDOM-UI provides a compiled CSS stylesheet that includes all necessary styles for the components. To use it in your application, you need to import it in your main application file:

<Source
  language="tsx"
  dark
  code={`// In your main application file (e.g., App.tsx, main.tsx, etc.)
import '@gdominguez210/gdom-ui/styles.css';`}
/>

## Tailwind Configuration

If you want to customize or extend GDOM-UI's styles using Tailwind, you'll need to configure your Tailwind setup to include the library's components. This step is only necessary if you plan to:
- Override or extend the library's default styles
- Use Tailwind's utility classes directly on GDOM-UI components
- Create custom variants or utilities that interact with GDOM-UI components

If you're only using the library's components with their default styles, you can skip this section and just use the CSS stylesheet provided above.

### Tailwind 4 Configuration

Tailwind 4 introduces automatic content detection and a CSS-first configuration approach. To include GDOM-UI in your project, add the following to your CSS file:

<Source
  language="css"
  dark
  code={`@import "tailwindcss";
@source "../node_modules/@gdominguez210/gdom-ui";`}
/>

This will automatically detect and include all Tailwind classes used in GDOM-UI components. Tailwind 4's new high-performance engine will handle this efficiently, with builds up to 5x faster than previous versions.

### Tailwind 3 Configuration

If you're using Tailwind 3, you'll need to use the traditional configuration approach. Add the following to your `tailwind.config.js`:

<Source
  language="js"
  dark
  code={`/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    // ... your existing content configuration
    './node_modules/@gdominguez210/gdom-ui/**/*.{js,ts,jsx,tsx}',
  ],
  // ... rest of your configuration
}`}
/>

> **Note**: GDOM-UI is built with Tailwind 4, which includes several modern features that might not be fully backwards compatible with Tailwind 3:
> - New high-performance engine
> - CSS-first configuration
> - Automatic content detection
> - Modern CSS features like cascade layers and registered custom properties
> - New color palette optimized for modern displays
> - Container queries and 3D transform utilities
> 
> While most components will work fine in Tailwind 3, you might encounter some styling differences or limitations.
