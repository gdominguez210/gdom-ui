# Core Concepts

Welcome to the Core Concepts section of the GDOM-UI documentation. This section provides an overview of the architectural patterns, design principles, and technical approaches used throughout the component library.

## Table of Contents

- **[Composability Over Configuration](/docs/core-concepts-composability-over-configuration--docs):** Emphasizes building UIs through component composition rather than complex configuration objects.

- **[Two-Tier Components](/docs/core-concepts-two-tier-components--docs):** Separates components into context-connected and primitive tiers to balance ease-of-use with customization flexibility.

- **[Polymorphic Components](/docs/core-concepts-polymorphic-components--docs):** Enables components to render as different HTML elements or React components using the `as` prop for maximum flexibility.

- **[Custom Hooks](/docs/core-concepts-custom-hooks--docs):** Provides reusable React hooks for common functionality that can be used across components.

- **[Styling Approach](/docs/core-concepts-styling-approach--docs):** Uses Tailwind CSS with intelligent class merging for consistent and customizable component styling.

- **[Accessibility](/docs/core-concepts-accessibility--docs):** Ensures all components are built with proper ARIA attributes, keyboard navigation, and screen reader support.

- **[Code Splitting](/docs/core-concepts-code-splitting--docs):** Optimizes bundle size through tree-shaking and allows importing individual components as needed.
